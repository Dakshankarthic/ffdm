02. MODEL VERSIONS AND COMPARISON CONTRACT
======================================================================
All main variants use ResNet-18 + fixed residual stem + small residual CNN
+ 64-channel FPN decoder. Same initialization, schedule and source sampling.
Definitions for one verified source/edit group:
A = canonical unedited photograph; C = canonical AI-edited image.
B = recipe(A); D = SAME recipe(C). Masks A/B empty; C/D verified masks.

T0: A,A,C,C with segmentation only. Duplicate forwards explicitly counted;
    this is the no-processed-controls reference with matched forward count.
T1: A,B,C,D with segmentation only.
T2: EXACT T1 inputs/sampling + A->B and C->D directed view consistency.
T2O: T2 + eligible outside-mask A->C and B->D consistency.
T3: T2O + optional auxiliary processing classifier, enabled only after T2O.
RGB_ONLY: T1 protocol, omit residual branch; separate architecture ablation.
L1_ABLATION: T2 inputs but symmetric probability L1; optional legacy objective.

Interpretation:
T1-T0 measures processed-control exposure with matched image forwards.
T2-T1 measures Lview with identical supervised examples.
T2O-T2 measures Loutside only on eligible pairs.
T3-T2O measures the auxiliary objective, not guaranteed disentanglement.
T2-T0 changes BOTH supervision and data: report it as the combined method.

Default final candidate F1 = best validated ResNet-18 variant.
Optional F2 = same winning objective with ResNet-50 RGB backbone, update
input projections for channels 256/512/1024/2048. Do not implement F2 before
the compact comparison works. Bigger model is not automatically final.
Final architecture/thresholds chosen on validation, never test feedback.

04. EXACT ARCHITECTURE AND TENSOR CONTRACT
======================================================================
Detector.forward(rgb) accepts float [B,3,H,W] in [0,1], no masks/recipes.
Returns {mask_logits: [B,1,H,W], processing_logits: optional [B,R]}.
Processing head absent/disabled for T0-T2O; metadata is never a model input.
Primary training tile H=W=384. Support arbitrary inference image sizes by
tiling/padding, not by forcing them through a distorted whole-image resize.

RGB encoder:
torchvision ResNet-18 with named pretrained weights saved in config/hash.
Normalization mean (.485,.456,.406), std (.229,.224,.225), RGB branch only.
384 input gives:
stride 4: [B,64,96,96]; 8: [B,128,48,48];
16: [B,256,24,24]; 32: [B,512,12,12].
Freeze BN affine requires_grad and running stats. Override train(mode):
super().train(mode); set every encoder BatchNorm2d.eval(); return self.
Convolutions remain trainable. Forensic/decoder blocks use GroupNorm(8,C).
Pretrained weights unavailable -> clear failure for research training;
random initialization permitted only in explicitly labelled unit/smoke tests.

High-pass stem:
register_buffer('kernels', tensor of shape [9,1,3,3]); grouped conv groups=3.
For each R/G/B channel apply these three exact 3x3 kernels:
Dx = [[0,0,0],[-0.5,0,0.5],[0,0,0]]
Dy = [[0,-0.5,0],[0,0,0],[0,0.5,0]]
Lap = [[0,0.25,0],[0.25,-1,0.25],[0,0.25,0]]
Use reflect padding for tiles (replicate fallback for tiny dimensions).
Output order R_Dx,R_Dy,R_Lap,G_Dx,...,B_Lap. No abs/clipping by default.
Residual encoder: four blocks, each Conv3x3 stride2 + GN + GELU followed by
Conv3x3 stride1 + GN + GELU. Channels 32,64,96,128.
Outputs: F2 [B,32,192,192], F4 [B,64,96,96],
F8 [B,96,48,48], F16 [B,128,24,24].

FPN decoder (all output widths 64; interpolation align_corners=False):
proj(X) = Conv1x1 to 64 + GN + GELU, separate parameters per input.
smooth(X) = Conv3x3 64->64 + GN + GELU.
P32 = proj(R32).
For s=16,8,4:
  Ls = Conv1x1(Concat[proj(Rs),proj(Fs)]) from 128->64 + GN + GELU.
  Ps = smooth(Ls + interpolate(P2s, size=Ls.shape[-2:])).
P2 = Conv3x3(Concat[interpolate(P4,size=F2.shape[-2:]),proj(F2)])
     from 128->64 + GN + GELU.
mask_logits = interpolate(Conv1x1(P2,64->1), size=input H,W).
Use target sizes, not assumptions about integer scale factors for odd inputs.
T3 optional classifier: GAP(P16) -> Linear64->32 -> GELU -> Linear32->R.

======================================================================
05. LOSSES: PRECISE DEFINITIONS
======================================================================
valid = real unpadded pixel AND not ignore-region. Mask values 0/1.
All reductions occur in float32, including when forward uses mixed precision.
Each image-view has supervised Lseg. Average views, then source groups.

Balanced BCE per image:
positive_loss = mean(softplus(-z)) over valid positive pixels, if any.
negative_loss = mean(softplus(z)) over valid negative pixels, if any.
If both present: BCE = 0.5*(positive_loss+negative_loss).
If one class present: use that class mean. If no valid pixels: skip and log.
Dice only for images/tiles with positive valid pixels:
1 - (2*sum(p*y)+1e-6)/(sum(p)+sum(y)+1e-6), valid pixels only.
For empty-mask tiles Dice=0; retain BCE, do not reward empty prediction as
perfect segmentation in the metrics. Lseg = BCE + Dice.

Directed view consistency:
q = sigmoid(z_clean).detach(), student z = z_degraded.
KL(q||sigmoid(z)) = BCEWithLogits(z,q) - H(q).
Compute teacher entropy with stable xlogy or clamped log probabilities.
No gradient through q; student receives gradient p-q without differentiating
the student sigmoid as a separate L1 multiplier. Small floating negatives
may be tolerated numerically; verify nonnegative within tolerance.
Reduce foreground and background separately, equally when both exist;
background-only reduction for pristine pairs. Respect masks/valid pixels.
Lview = mean of A->B and C->D. Both sides ALSO have supervised Lseg.
Do not gate teacher pixels by confidence in v1.1; any later gating is an
explicit ablation with its effect on supervision coverage reported.

Outside consistency T2O:
Same directed KL from A.detach()->C and B.detach()->D, outside dilated edit
mask and ignore regions, only if outside_pair_eligible is true.
Compute dilation on full-image mask before crop, preventing tile-edge errors.
Mask negatives still receive ordinary segmentation supervision.
Default debug radius 16 canonical pixels is PROVISIONAL, not a proven radius.
Before research training, select recipe-specific radii from train-only
distance-to-mask difference plots and no-edit controls; save calibration JSON.
If no finite local exclusion isolates a comparable background, disable this
pair for Loutside. Full-frame VAE traces cannot be fixed by arbitrary dilation.
Keep radius fixed across variants and report eligible-pair coverage.

Lprocessing T3: cross entropy for known recipe IDs, ignore unknown labels.
Total loss = Lseg + ramp*0.1*Lview + ramp*0.1*Loutside + 0.05*Lprocessing,
with absent terms exactly disabled by variant. ramp=min(1,step/500).
Supervised warm-up is not evidence of a correct teacher; inspect outputs.
Optional legacy L1 objective must be named and logged distinctly.

06. SAMPLER, OPTIMIZER AND COMPUTE PARITY
======================================================================
One optimizer update = 2 source/edit groups x 4 views = 8 tile forwards.
Process one group (4 tiles) at a time, accumulate over two groups, dividing
loss by two; do NOT divide again by eight after per-view/group averaging.
If memory requires sequential views, use detached teacher outputs and
backpropagate student losses carefully without retain_graph leaks. Test that
accumulated gradients match the joint implementation within tolerance.
Measure actual allocated/reserved memory; do not assume an audit VRAM estimate.

Persist schedule.jsonl listing source group, edit ID, crop coordinates, recipe
and transform seed for every step. Reuse it in T1/T2/T2O/T3.
For each two-group step, use one edit-intersecting crop and one uniformly
sampled crop (prefer verified background where available). A/B always have
empty edit labels; C/D may be negative if crop misses the edit. Record actual
positive/negative tile counts and full-image edit size separately.
T0 uses corresponding A,A,C,C with the same origins and source sequence.
Identical geometry transforms across all views; v1.1 starts without random
geometric augmentation to simplify verification. Add flips only as a logged
experiment, shared across variants.

AdamW: RGB lr=1e-4, new layers lr=3e-4, weight_decay=1e-4.
Initial pilot budget 5,000 optimizer steps; validate every 500.
Linear LR warm-up 100 steps, then cosine decay to 0.1 times initial LR.
AMP on compatible CUDA, gradient scaler, clip gradient norm at 1 after
unscaling. No silent skipped NaN steps: log failures and halt to diagnose

======================================================================
07. FULL-IMAGE INFERENCE AND DECISION RULES
======================================================================
Tile size 384, stride 256. Starts in each axis are sorted unique values from
regular stride positions plus max(0,dimension-384); smaller images pad once.
Use identical crop coordinates for matched training views. Never drop edges.
Replicate padding for undersized images; ignore padding in losses/metrics.
Full-image continuous output always matches decoded/oriented input H,W.

Weight window W=max(outer(hann(384),hann(384)),1e-3), float32.
Default: sum(W*sigmoid(tile_logits))/sum(W).
Logit ablation: sigmoid(sum(W*tile_logits)/sum(W)).
Strip padding and ensure weight_sum>0 at every real pixel. Tiling can create
context artifacts; export seam diagnostics, not just attractive overlays.

Score candidates on the merged probability map:
mean top ceil(f*N) for f=.001,.005,.01,.02;
mean top min(K,N) for K=2048,4096. At least one pixel in every pool.
Primary debug defaults: probability blending, K=2048, mask threshold=.5.
Debug defaults are NOT validation-selected operating points.

Validation selection, two distinct thresholds:
- t_mask: choose on development validation from .05,.10,...,.95 to maximize
  macro edited-image IoU; tie -> higher threshold. Report tiny and all-edit
  metrics plus genuine positive-pixel fraction. Do not set t_mask from image
  score FPR, because these are different quantities.
- t_image: score threshold for desired image FPR on a separate calibration
  source split if data permit. Enumerate thresholds/ties deterministically;
  decision is score>t_image. Choose most sensitive threshold satisfying the
  empirical target on calibration negatives; include a reject-all option.
- Choose pooling/blending on development validation before calibration.
- If limited data force shared validation, disclose selection optimism and
  keep final test independent. Tiny debug sets cannot certify low FPR.

Freeze inference_policy.json with model hash, split hashes, blending, pooling,
t_mask, t_image, score direction, target/observed calibration FPR and counts.
Default full mask is not gated by image score; detection and localization
metrics remain separate. Any gated product display must be separately labelled.

Output per image: probability.npy or memory-mapped equivalent, mask.png,
overlay.png, result.json with raw score/decision/policy hash/runtime/dimensions.
No claim "AI probability 95%" without separately verified calibration.
