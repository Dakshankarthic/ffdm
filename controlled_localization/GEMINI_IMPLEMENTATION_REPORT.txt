2. Source Code (src/controlled_localization/):
   - data/schema.py: ManifestRecord dataclass with strict JSONL validation, view roles
     (A, B, C, D), status, compositing modes, and F10 full_frame_decode eligibility.
   - data/canonicalize.py: Lossless RGB conversion, EXIF transposition, and deterministic
     recipe generators (JPEG Q70/85/95 4:2:0, Gaussian blur s05, identity).
   - data/audit.py: Mask semantics, no-op detection (d(x) = mean_RGB(|C-A|)), inside/outside
     L1 difference computation, and quarantine logic.
   - data/pairs.py: FourViewGroup abstractions (A, B, C, D), pre-crop circular mask
     dilation (16px), and outside-mask consistency filtering.
   - data/tiles.py: Sliding 384x384 tiling with 256 stride, complete corner coverage,
     replicate padding for small images, and Hann-windowed probability/logit blending.
   - models/rgb_encoder.py: ResNet-18 RGB encoder with ImageNet normalization, permanently
     frozen BatchNorm affine weights and running statistics (F3 resolution), and overridden train().
   - models/residual_encoder.py: Fixed high-pass stem with 9 buffers (Dx, Dy, Lap) grouped
     across RGB (zero parameters, F2 resolution), followed by 4-stage GroupNorm residual encoder.
   - models/decoder.py: 64-channel FPN decoder with exact spatial size interpolation (F1 resolution)
     and optional T3 processing classifier head.
   - models/detector.py: ControlledLocalizationDetector integrating RGB encoder, residual
     encoder, and decoder. Deployed forward(rgb) takes ONE image only (no masks or originals).
   - losses/segmentation.py: Supervised balanced BCE + Dice (for non-empty masks) with
     all reductions in float32.
   - losses/consistency.py: Directed Bernoulli KL view consistency (A->B, C->D) with detached
     teacher (F6 resolution), and outside-mask consistency (A->C, B->D) on dilated regions.
   - policy.py: InferencePolicy and score pooling (top-K and top-fraction) with frozen JSON export.
   - metrics.py: Confusion matrices, IoU/F1, original edit area stratification (<0.5%, 0.5-2%,
     2-10%, >10%), and streaming 4096-bin logit histogram AP (F11 resolution).
   - utils.py: Seeding, SHA256 checksums, device resolution, and visual heatmap overlays.
   - train.py: Training loop, AdamW optimizer with parameter groups, cosine scheduler,
     AMP GradScaler, 8-tile accumulation per step (F7 resolution), and atomic checkpointing.
   - infer.py: Single-image inference CLI (strictly accepts checkpoint, image, policy).
   - evaluate.py: Full manifest evaluation CLI generating metrics.json and CSV predictions.
   - audit_data.py: CLI for auditing manifests and quarantining no-op samples.
   - build_controls.py: CLI for generating matched views B and D from canonical A and C.
   - build_schedule.py: CLI for generating reproducible step-level tile schedules.
   - profile.py: CLI for hardware memory and execution speed benchmarking.
   - overfit_check.py: Stage 4 training runner on verified 8-group four-view batches.

3. Experiment Configurations (configs/):
   - debug.yaml: Fast smoke testing and hardware profiling configuration.

   - t2o.yaml: T2 + eligible outside-mask consistency (A->C, B->D).
