Detailed Technical & Mathematical Specification3.1 Stage 1: Differentiable "Echo" + Haar Wavelet Forensic StemGiven an RGB image $I \in [0, 1]^{B \times 3 \times H \times W}$:3 Differentiable Perturbations:$I_{\text{gauss}}$: $5 \times 5$ Gaussian blur ($\sigma = 1.0$)$I_{\text{dct}}$: Differentiable $8 \times 8$ block smoothing / high-frequency quantization proxy$I_{\text{med}}$: $3 \times 3$ local average / edge-preserving smooth proxyEcho Residual Maps: $E_k = \vert{}I - I_k\vert{}$ for $k \in \{\text{gauss}, \text{dct}, \text{med}\}$ ($9$ channels total).1-Level 2D Haar Wavelet Transform: Extracts the $LH, HL, HH$ high-frequency subbands of the luminance channel ($3$ channels, upsampled to $H \times W$).Combined Forensic Input: $X_{\text{for}} = \mathrm{Concat}(E_{\text{gauss}}, E_{\text{dct}}, E_{\text{med}}, \text{Haar}_{LH, HL, HH}) \in \mathbb{R}^{B \times 12 \times H \times W}$.3.2 Stage 2: Hollow Neighbor-Ring Disagreement Module (NRDM)Let $F \in \mathbb{R}^{B \times C \times h \times w}$ be a spatial feature map (e.g., $64 \times 64$).Define a fixed $3 \times 3$ hollow ring kernel $W_{\text{ring}}$ where the center weight is $0$ and the 8 surrounding neighbor weights are $\frac{1}{8}$.Compute the local neighborhood mean feature $\bar{F}_{\text{ring}} = \mathrm{DepthwiseConv2d}(F, W_{\text{ring}})$.Compute both Cosine Disagreement and L2 Disagreement at every spatial location $(u, v)$:
$$D_{\text{cos}}(u, v) = 1 - \frac{\langle F(u,v), \bar{F}_{\text{ring}}(u,v) \rangle}{\Vert{}F(u,v)\Vert{}_2 \, \Vert{}\bar{F}_{\text{ring}}(u,v)\Vert{}_2 + \epsilon}$$$$D_{L_2}(u, v) = \Vert{}F(u,v) - \bar{F}_{\text{ring}}(u,v)\Vert{}_2$$Concatenate $[F, D_{\text{cos}}, D_{L_2}]$ and pass through a $1 \times 1$ fusion convolution. This explicitly highlights localized anomalies while suppressing uniform global VAE background traces.3.3 Stage 3: Seam-Loop + Inside-Fill Dual Decoder (Pass 1)To prevent blurry masks on small edits, the Pass-1 decoder predicts two coupled spatial maps:Seam Head ($\hat{B}_1 \in [0, 1]^{B \times 1 \times 512 \times 512}$): Supervised by the morphological boundary $B_{\text{gt}} = \mathrm{Dilate}(M_{\text{gt}}, 3) - \mathrm{Erode}(M_{\text{gt}}, 3)$.Fill Head ($\hat{M}_1 \in [0, 1]^{B \times 1 \times 512 \times 512}$): Uses progressive transposed/bilinear upsampling from $32 \times 32 \rightarrow 64 \times 64 \rightarrow 128 \times 128 \rightarrow 512 \times 512$, gated by the NRDM disagreement map and seam features $\hat{B}_1$.Pass-1 Detection Head ($\hat{y}_1 \in [0, 1]^{B \times 1}$): Combines Global Average Pooling + Top-$k$ Max Pooling of the disagreement-weighted features to output the initial manipulation probability.3.4 Stage 4: "Check-Twice" High-Res Zoom Verification (Pass 2)When an edit is tiny (<2% of the image), downsampling the whole image to $512 \times 512$ destroys fine pixel traces. Pass 2 fixes this:Peak Selection: Apply $15 \times 15$ Non-Maximum Suppression (NMS) on $\hat{M}_1$ to extract the top-$K$ ($K=2$) suspicious centers $(x_k, y_k)$, plus $1$ Clean Reference Center $(x_{\text{ref}}, y_{\text{ref}})$ at the minimum of $\hat{M}_1$.Native-Resolution Cropping: Extract $256 \times 256$ crops from the original unresized image $I$ (clamped to image bounds; fallback to upsampled crop if $I$ is already $\le 512$).Contrastive Noise-Floor Verification:Extract Echo + Wavelet + NRDM embeddings $e_{\text{susp}}^{(k)}$ for each suspicious crop and $e_{\text{ref}}$ for the clean reference crop from the same image.Compute a Verification Gate $\alpha_k = \sigma(\mathrm{MLP}([e_{\text{susp}}^{(k)}, e_{\text{ref}}, \vert{}e_{\text{susp}}^{(k)} - e_{\text{ref}}\vert{}])) \in [0, 1]$.Decode a high-res local mask $\hat{M}_{2}^{(k)} \in [0, 1]^{256 \times 256}$ for each crop.Final Fusion:Paste $\alpha_k \cdot \hat{M}_{2}^{(k)}$ back into the full-resolution canvas and blend with $\hat{M}_1$ to produce $\hat{M}_{\text{final}}$.Final image-level score: $\hat{y}_{\text{final}} = 0.5 \, \hat{y}_1 + 0.5 \, \max_k \alpha_k$.3.5 Multi-Task Loss Function (Tuned for High Accuracy & Tiny Edits)$$\mathcal{L} = 1.0\,\mathcal{L}_{\text{Focal}}(\hat{M}, M_{\text{gt}}) + 1.0\,\mathcal{L}_{\text{SoftDice}}(\hat{M}, M_{\text{gt}}) + 0.5\,\mathcal{L}_{\text{Seam}}(\hat{B}_1, B_{\text{gt}}) + 1.0\,\mathcal{L}_{\text{BCE}}(\hat{y}_{\text{final}}, y_{\text{gt}}) + 0.3\,\mathcal{L}_{\text{Contrastive}}(e_{\text{susp}}, e_{\text{ref}})$$4. ### 1. Core Algorithm Architecture to Implement
Implement "EchoSeam-Net" from scratch (do NOT use FUSED or generic CLIP-only wrappers). The pipeline takes a raw RGB image `x_orig` (any resolution, e.g., `(B, 3, H, W)`) and a resized global tensor `x_512` (`(B, 3, 512, 512)`) and returns:
- `"pred_score"`: `(B, 1)` calibrated probability ("Possibly AI-Edited")
- `"pass1_score"`: `(B, 1)` Pass-1 global score
- `"pass2_verify_scores"`: `(B, K)` Pass-2 verification gate scores for top-K=2 suspicious crops
- `"pred_mask"`: `(B, 1, 512, 512)` final blended suspicious region probability heatmap
- `"pred_seam"`: `(B, 1, 512, 512)` predicted manipulation boundary/seam map
- `"crop_boxes"`: `(B, K, 4)` pixel coordinates of the zoomed-in suspicious regions checked in Pass 2

Build these exact modules inside `echoseam_net/`:
1. `echoseam_net/models/forensic_stem.py`:
   - `EchoWaveletStem(nn.Module)`: Computes 3 differentiable perturbations (5x5 Gaussian blur sigma=1.0, 8x8 DCT-proxy block smoothing, 3x3 local average), subtracts each from input to get 9 Echo residual channels, computes 1-level 2D Haar Wavelet (LH, HL, HH) on luminance (upsampled back to HxW), and concatenates into a 12-channel forensic tensor followed by a lightweight 4-stage residual ConvNet encoder outputting multi-scale forensic maps (`128x128`, `64x64`, `32x32`).
2. `echoseam_net/models/neighbor_ring.py`:
   - `HollowNeighborRingDisagreement(channels)`: Uses a non-trainable `3x3` depthwise conv kernel with center=0 and 8 neighbors=1/8 to compute local neighborhood mean features, then computes per-pixel Cosine Disagreement and L2 Disagreement maps, concatenating them back with the feature map via a `1x1` conv + GroupNorm + GELU.
3. `echoseam_net/models/semantic_backbone.py`:

4. `echoseam_net/models/seam_fill_decoder.py`:
